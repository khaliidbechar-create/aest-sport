# A.E.S.T. Taounate
Application de gestion d'école sportive, optimisée pour Android et fonctionnement hors ligne.

## Fonctions
- Joueurs : ajout, modification, suppression, recherche et filtre pack.
- Présences : suivi par date.
- Finances : recettes, payeurs et packs.
- Sauvegarde/restauration JSON.
- Français / arabe.
- PWA installable et cache hors ligne.
- Aucun CDN externe.

## APK
Le workflow `.github/workflows/android.yml` construit automatiquement un APK debug avec Capacitor.
Après le build GitHub : Actions → workflow → Artifacts → `AEST-Taounate-debug`.
